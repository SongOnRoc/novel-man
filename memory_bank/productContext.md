# 产品上下文 (Product Context)

## 1. 核心价值

构建一个跨平台、交互体验良好的 AI 写作管理工具，旨在为网络小说作家提供从灵感、创作、管理到发布的完整解决方案。

## 2. MVP (V1.0) 核心功能

MVP 版本的核心是提供一个功能完善的 AI 辅助写作基础版，让用户能够高效地完成核心创作任务。

### 2.1. AI 写作助手
- 拥有续写、改写、扩写、缩写、仿写、文本润色、创意灵感生成等功能。
- 可以实现对话生成、情节建议、总结、信息提取等。

### 2.2. 编辑器与内容管理
- 基于titap的编辑器组件，支持单页面模式以及页面内嵌入模式，实现了文本的高效编辑和管理。
- 自动保存、字数统计。
- 章节/草稿等写作功能的管理（创建、编辑、删除、排序、草稿箱）。

### 2.3. 作品管理
- 作品的创建、删除、编辑（标题、简介等）。
- 作品大纲、章节、草稿、分卷功能。

### 2.4. 核心素材管理
- **角色管理**: 创建角色档案，管理基本信息和关系网络。
- **世界观设定**: 管理地点、势力、规则等。
- **速查表**: 在写作时可以快速查阅，修改更新，以及标记等。

### 2.5. 用户系统
- 用户注册、登录。
- 用户偏好设置（界面、编辑器设置、AI基础设置）。
