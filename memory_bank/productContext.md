# 产品上下文 (Product Context)

## 项目名称
novel-man

## 项目愿景
打造一个全面、智能的小说写作平台，简化作者的创作流程。该平台旨在提供草稿撰写、世界观构建、角色管理和 AI 辅助写作工具，帮助作家专注于故事讲述，而系统则负责组织和润色。

## 核心价值主张
- **结构化写作**: 用于管理章节、大纲和草稿的工具。
- **世界观构建**: 用于追踪角色、地点和设定的专用功能。
- **AI 辅助**: 利用 LLM 提供智能建议、续写和头脑风暴伙伴。
- **无干扰环境**: 干净、现代的编辑器界面。

## 当前重点
**AI 写作助手集成**: 当前的直接目标是实现并集成 AI 写作助手功能。这涉及搭建后端基础设施（可能使用 LangChain 或直接调用 LLM API）以支持文本生成、情节建议和角色聊天等功能，并将这些功能连接到前端编辑器和聊天界面。
