# 系统模式

---
### **Next.js + TypeScript + Tailwind CSS**
- **[2025-07-12 15:28:03]**
- **描述**: 这是前端开发的核心技术栈。
  - **Next.js**: 用于服务器端渲染 (SSR)、静态站点生成 (SSG) 和文件系统路由，提供了强大的性能和开发体验。
  - **TypeScript**: 为 JavaScript 添加了静态类型，增强了代码的可维护性和健壮性，减少了运行时错误。
  - **Tailwind CSS**: 一个实用工具优先的 CSS 框架，可以快速构建自定义设计，而无需编写大量自定义 CSS。
- **采用原因**: 该技术栈是现代 Web 开发的黄金标准之一，特别适合构建需要高性能、强类型和灵活样式的复杂单页应用程序 (SPA)。它与 `shadcn/ui` 等流行的UI组件库兼容良好，并得到了 `frontend` 目录中现有 CDK 项目的验证。

---
### **Shadcn/ui 组件库**
- **[2025-07-12 15:28:03]**
- **描述**: 一个可重用、可组合的 UI 组件集合，构建在 Radix UI 和 Tailwind CSS 之上。它不是一个传统的组件库，而是提供了一系列可以复制粘贴到项目中并根据需要进行修改的组件。
- **采用原因**: 提供了高度的可定制性和灵活性。由于组件代码直接存在于项目中，因此可以轻松地对其进行样式和行为的调整，以满足品牌和功能需求。这避免了传统组件库中常见的样式覆盖和功能限制问题。

---
### **Zustand 状态管理**
- **[2025-07-12 15:28:03]**
- **描述**: 一个轻量、快速、可扩展的 React 状态管理库。它使用简单的 API 和钩子来管理全局和本地状态，而无需大量的模板代码。
- **采用原因**: 相比于 Redux 等更复杂的状态管理库，Zustand 提供了更简洁、更直观的解决方案。它的学习曲线平缓，性能出色，并且能够很好地与 React Hooks 集成，非常适合中小型项目以及需要快速迭代的场景。

---
### **Tiptap 编辑器**
- **[2025-07-12 15:28:03]**
- **描述**: 一个基于 Prosemirror 的无头 (headless) 富文本编辑器框架。它提供了强大的可扩展性，允许开发者构建完全自定义的编辑器体验。
- **采用原因**: Tiptap 的无头架构使其能够与任何 UI 框架（包括 React）和样式方案（包括 Tailwind CSS）无缝集成。它支持丰富的扩展，如书签、提及、协作编辑等，使其成为构建功能强大的自定义编辑器的理想选择。
