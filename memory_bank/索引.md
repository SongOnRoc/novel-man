# 📂 frontend 功能-代码映射报告

## 🏗️ 项目概览
- **技术栈**: Next.js (v15.4.2) + React (v19.0.0) + TypeScript + TanStack React Query (v5.83.0) + Tiptap (v2.26.0)
- **架构模式**: 功能驱动架构 (Feature-based) 结合 Next.js App Router 页面路由
- **状态管理**: Zustand (v5.0.6) 用于客户端全局状态, TanStack React Query 用于服务端状态缓存
- **样式方案**: Tailwind CSS + shadcn/ui (基于 Radix UI)
- **构建工具**: Next.js (内置 Turbopack/Webpack)
- **包管理**: pnpm (v10.9.0)

## 📊 功能模块统计
- **页面级组件**: 23 个 (在 `src/app` 目录下定义的主要页面/路由)
- **可复用组件**: 60 个 (在 `src/components` 和 `src/features` 下的通用及功能组件)
- **业务逻辑模块**: 15 个 (在 `src/hooks` 和 `src/lib/services` 下的 Hooks 和 Services)
- **样式文件**: 2 个 (全局样式 `globals.css` 和自定义样式 `liquid-glass.css`)
- **配置文件**: 10 个 (项目级配置，如 `next.config.ts`, `tsconfig.json` 等)

## 🗂️ 目录结构概览
```
frontend/
├── src/
│   ├── app/                    # Next.js App Router 路由和页面
│   │   ├── (auth)/             # 认证相关页面 (登录, 注册)
│   │   └── (main)/             # 主应用功能页面 (仪表盘, 作品, 工具等)
│   ├── components/             # 可复用的UI和业务组件
│   │   ├── common/             # 通用业务组件
│   │   └── ui/                 # shadcn/ui 基础UI组件
│   ├── contexts/               # React Context
│   ├── features/               # 按功能划分的模块化组件
│   ├── hooks/                  # 自定义 React Hooks
│   ├── lib/                    # 库、工具函数、服务和API
│   │   ├── api/generated/      # Orval 自动生成的API客户端
│   │   ├── config/             # 项目配置 (如导航)
│   │   ├── editor/             # Tiptap 编辑器扩展
│   │   ├── mock/               # 模拟数据
│   │   └── services/           # 业务服务层
│   ├── styles/                 # 全局和自定义样式
│   └── types/                  # TypeScript 类型定义
└── ...                         # 其他配置文件
```
