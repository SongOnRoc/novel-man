# 📂 frontend 功能-代码映射报告

## 🏗️ 项目概览
- **技术栈**: Next.js (React) + TypeScript + React Query + Zustand + Tailwind CSS + shadcn/ui + Tiptap
- **架构模式**: Component-based, Feature-based (功能驱动)
- **状态管理**: React Query (服务端状态) + Zustand (客户端状态)
- **样式方案**: Tailwind CSS + shadcn/ui
- **构建工具**: Next.js CLI (内置 Turbopack/Webpack)
- **包管理**: pnpm

## 📊 功能模块统计
- **页面级组件**: 约 15+ 个 (已分析 5 个核心页面)
- **可复用组件**: 约 50+ 个 (包括通用 UI 和业务功能组件)
- **业务逻辑模块**: 10+ 个核心 Hooks (位于 `src/hooks`)
- **样式文件**: 2 个全局样式文件 (`globals.css`, `liquid-glass.css`)
- **配置文件**: 8+ 个 (Next.js, TypeScript, Tailwind, Orval 等)

## 🗂️ 目录结构概览
```
frontend/
├── src/
│   ├── app/                    # Next.js App Router 页面和路由
│   │   ├── (auth)/             # 认证相关页面 (登录/注册)
│   │   └── (main)/             # 主应用布局和页面
│   ├── components/             # 通用及UI组件 (shadcn/ui)
│   ├── features/               # 功能模块化目录
│   │   ├── chapters/
│   │   ├── drafts/
│   │   ├── editor/
│   │   ├── works/
│   │   └── worldview/
│   ├── hooks/                  # 自定义React Hooks，封装业务逻辑
│   ├── lib/                    # 核心库、工具函数和API层
│   │   ├── api/generated/      # Orval 自动生成的API客户端
│   │   ├── editor/             # Tiptap 编辑器扩展
│   │   └── services/           # 对API调用的高级封装
│   └── styles/                 # 全局样式
└── public/                     # 静态资源
```
