# 📂 frontend 功能-代码映射报告

## 🏗️ 项目概览
- **技术栈**: Next.js (App Router), React 19, TypeScript, Tailwind CSS
- **架构模式**: Component-based, Feature-based (代码按功能/页面组织在 `src/app` 和 `src/features` 目录下)
- **状态管理**: Zustand (客户端状态), TanStack React Query (服务器状态缓存)
- **样式方案**: Tailwind CSS + shadcn/ui (UI组件库)
- **构建工具**: Next.js CLI (底层使用Vite)
- **包管理**: pnpm

## 📊 功能模块统计
- **页面级组件**: ~28 个 (分布在 `src/app` 目录下的 `page.tsx` 文件)
- **可复用组件**: ~40 个 (包括 `src/components/ui` 下的 ~28 个基础UI组件, `src/components/common` 和 `src/features` 下的 ~12 个通用及业务组件)
- **业务逻辑模块**: ~15 个 (分布在 `src/hooks` 目录下，按业务领域划分)
- **样式文件**: 1 个 (`src/app/globals.css`)
- **配置文件**: 10+ 个 (Next.js, TypeScript, PostCSS, ESLint, Vitest 等)

## 🗂️ 目录结构概览
```
frontend/
├── src/
│   ├── app/                 # 路由和页面
│   │   ├── (auth)/          # 认证相关页面 (登录/注册)
│   │   ├── (main)/          # 主应用页面 (仪表盘/作品/章节等)
│   │   └── api/             # API 路由
│   ├── components/          # 可复用组件
│   │   ├── common/          # 通用布局和功能组件
│   │   └── ui/              # shadcn/ui 基础组件
│   ├── features/            # 特定功能的组件和逻辑
│   ├── hooks/               # 自定义 Hooks (业务逻辑)
│   ├── lib/                 # 库和工具函数
│   │   ├── api/             # API 请求相关 (orval 生成)
│   │   └── utils.ts         # 通用工具函数
│   └── contexts/            # React Contexts
└── ...
```
