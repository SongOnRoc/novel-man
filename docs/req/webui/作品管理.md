# 章节
1、章节创建逻辑需要自动检查当前已有的章节序号是什么，然后创建时标题自动累加
2、章节列表不能按照更新时间来排序，需要按照章节顺序来排序，可以正序倒序排列
3、作品管理里的章节页面需要可以提取细纲，提取人物角色，提取设定等。在桌面端考虑的是每个章节可以有个点击向右展开的小箭头，执行逻辑如下：点击弹出对话框可以选择操作大纲还是角色还是设定，选择大纲后，可以继续选择执行大纲提取，大纲编辑，大纲删除等等选项，选择具体操作如大纲提取，可以把当前章节的前文内容以及大纲提取的提示词注入到ai写作助手中，ai助手完成大纲提取后，返回大纲提取结果，其余的角色提取等功能类似，移动端的UI布局需要更巧妙友好的设计。
4、UI设计上需要考虑章节和大纲的对照联系交互体验。
