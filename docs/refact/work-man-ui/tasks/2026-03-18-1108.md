# 本次做了什么

- 为作品章节页新增“调整章节号”首版入口：在章节列表操作菜单中增加“调整章节号”，点击后打开目标章节号对话框。
- 新增纯逻辑重排工具 `chapterReorder.ts`：按 `displayOrder + id` 排序后执行“移除 -> 插入 -> 连续重算 `displayOrder=1..N`”，并复用 `normalizeChapterTitle` 同步修正章节标题前缀。
- 在章节页中接入逐条更新：确认调整后，对受影响章节依次调用 `updateChapter`，成功则提示，失败则 toast 提示并 `router.refresh()` 回到服务端状态。
- 补充单测：
  - `chapterReorder.test.ts` 覆盖向前插入、向后插入、无变化三类重排场景。
  - `chapters/page.test.tsx` 覆盖“可打开调整章节号入口”。

# 为什么这么做

- proposal 阶段 5 的最小闭环目标是“插入并顺延 + 标题前缀同步修正”，数值对话框比拖拽更稳，更容易先把业务规则做正确。
- 通过抽离纯逻辑 helper，可以先把重排规则和标题修正规则固定下来，再把页面交互接上，降低页面复杂度。
