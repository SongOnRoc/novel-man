## 2. 核心组件设计

### 2.1 通用文件处理服务

#### 2.1.1 文件解析器 (FileParser)

```go
// backend/utils/upload/parser.go

package upload

import (
    "archive/zip"
    "encoding/json"
    "io"
    "mime/multipart"
    "path/filepath"
    "strings"
)

// FileType 文件类型枚举
type FileType string

const (
    FileTypeTxt  FileType = "txt"
    FileTypeMd   FileType = "md"
    FileTypeJson FileType = "json"
    FileTypeZip  FileType = "zip"
)

// ParsedFile 解析后的文件
type ParsedFile struct {
    Name     string
    Type     FileType
    Content  []byte
    Metadata map[string]interface{}
}

// FileParser 文件解析器接口
type FileParser interface {
    Parse(file *multipart.FileHeader) ([]*ParsedFile, error)
    SupportedTypes() []FileType
}
```

#### 2.1.2 文件验证器 (Validator)

```go
// backend/utils/upload/validator.go

package upload

import (
    "errors"
    "mime/multipart"
    "path/filepath"
    "strings"
)

const (
    MaxFileSize     = 10 << 20  // 10MB
    MaxZipSize      = 50 << 20  // 50MB
    MaxFilesInZip   = 100
)

var (
    ErrFileTooLarge     = errors.New("file size exceeds limit")
    ErrInvalidFileType  = errors.New("invalid file type")
    ErrTooManyFiles     = errors.New("too many files in archive")
)

// FileValidator 文件验证器
type FileValidator struct {
    allowedTypes []FileType
    maxSize      int64
}

func NewFileValidator(allowedTypes []FileType, maxSize int64) *FileValidator {
    return &FileValidator{
        allowedTypes: allowedTypes,
        maxSize:      maxSize,
    }
}

func (v *FileValidator) Validate(file *multipart.FileHeader) error {
    // 验证文件大小
    if file.Size > v.maxSize {
        return ErrFileTooLarge
    }
    
    // 验证文件类型
    ext := strings.TrimPrefix(filepath.Ext(file.Filename), ".")
    fileType := FileType(ext)
    
    allowed := false
    for _, t := range v.allowedTypes {
        if t == fileType {
            allowed = true
            break
        }
    }
    
    if !allowed {
        return ErrInvalidFileType
    }
    
    return nil
}
```

### 2.3 提示词导入实现

```go
// backend/internal/services/prompts/import_service.go

package prompts

import (
    "encoding/json"
    "mime/multipart"
    "novel-man/backend/internal/contracts"
    "novel-man/backend/internal/models"
    "novel-man/backend/utils/context"
    "novel-man/backend/utils/upload"
    "path/filepath"
    "strings"
)

type PromptImporter struct {
    service contracts.GenericCRUD[models.Prompt, uint]
    parser  upload.FileParser
}

func NewPromptImporter(service contracts.GenericCRUD[models.Prompt, uint]) *PromptImporter {
    return &PromptImporter{
        service: service,
        parser:  upload.NewDefaultParser(),
    }
}

func (i *PromptImporter) Import(ctx context.Context, file *multipart.FileHeader, userID uint) (*contracts.ImportResult, error) {
    result := &contracts.ImportResult{}
    
    // 解析文件
    parsedFiles, err := i.parser.Parse(file)
    if err != nil {
        return nil, err
    }
    
    result.Total = len(parsedFiles)
    
    // 处理每个文件
    for _, pf := range parsedFiles {
        if err := i.processFile(ctx, pf, userID); err != nil {
            result.Failed++
            result.Errors = append(result.Errors, err.Error())
        } else {
            result.Success++
        }
    }
    
    return result, nil
}

func (i *PromptImporter) processFile(ctx context.Context, pf *upload.ParsedFile, userID uint) error {
    switch pf.Type {
    case upload.FileTypeJson:
        return i.processJsonFile(ctx, pf, userID)
    case upload.FileTypeTxt, upload.FileTypeMd:
        return i.processTextFile(ctx, pf, userID)
    default:
        return upload.ErrInvalidFileType
    }
}

func (i *PromptImporter) processJsonFile(ctx context.Context, pf *upload.ParsedFile, userID uint) error {
    var prompts []struct {
        Title       string   `json:"title"`
        Content     string   `json:"content"`
        Description string   `json:"description"`
        PrimaryTag  string   `json:"primaryTag"`
        Categories  []string `json:"categories"`
        FooterTags  []string `json:"footerTags"`
    }
    
    if err := json.Unmarshal(pf.Content, &prompts); err != nil {
        return err
    }
    
    for _, p := range prompts {
        prompt := &models.Prompt{
            UserID:      userID,
            Title:       p.Title,
            Content:     p.Content,
            Description: p.Description,
            PrimaryTag:  p.PrimaryTag,
            Status:      "active",
        }
        
        if err := i.service.Create(ctx, prompt); err != nil {
            return err
        }
    }
    
    return nil
}

func (i *PromptImporter) processTextFile(ctx context.Context, pf *upload.ParsedFile, userID uint) error {
    title := strings.TrimSuffix(pf.Name, filepath.Ext(pf.Name))
    
    prompt := &models.Prompt{
        UserID:  userID,
        Title:   title,
        Content: string(pf.Content),
        Status:  "active",
    }
    
    return i.service.Create(ctx, prompt)
}
```

## 3. API 端点详细设计

### 3.1 提示词导入 API

**端点**: `POST /api/v1/prompts/import`

**请求头**:
```
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

**请求体**:
```
file: <文件>
```

**响应** (200 OK):
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "success": 5,
    "failed": 1,
    "total": 6,
    "errors": [
      "文件格式错误: invalid.txt"
    ]
  }
}
```

**错误响应**:
- 400: 文件格式不支持
- 401: 未授权
- 413: 文件过大
- 500: 服务器错误

## 4. 数据流程

### 4.1 提示词导入流程

```
1. 用户选择文件 → 前端验证
2. 上传文件 → API Gateway
3. 认证中间件 → 验证用户身份
4. 文件验证中间件 → 验证文件类型和大小
5. 控制器接收 → 调用导入服务
6. 文件解析 → 根据类型解析内容
7. 数据验证 → 验证数据完整性
8. 批量创建 → 保存到数据库
9. 返回结果 → 成功/失败统计
```

### 4.2 错误处理流程

```
1. 文件验证失败 → 返回 400 错误
2. 解析失败 → 记录错误，继续处理其他文件
3. 数据验证失败 → 记录错误，继续处理
4. 数据库错误 → 记录错误，继续处理
5. 返回结果 → 包含所有错误信息
```
