## 功能概述

为小说管理系统后端添加通用的文件上传和导入功能，支持：

- **提示词模块**: .txt, .md, .json, .zip
- **作品模块**: .json
- **章节模块**: .txt, .md

## 🚀 架构亮点

### 零重复代码设计
通过**反射+标签**实现真正的通用导入系统：
- 新增业务模块只需在模型上添加 `json_field` 标签
- 复用通用映射器，无需重复编写解析逻辑
- 编译时类型检查，运行时自动映射

### 类型安全保障
- 编译时发现标签配置错误
- 反射自动处理类型匹配
- 避免手动类型转换错误

### 高度可扩展性
- 新增业务模块：只需模型标签配置
- 新文件格式：添加对应解析器
- 灵活配置：通过标签控制映射行为

## 📁 技术架构

### 核心组件
1. **模块化解析器** - 按文件类型分离（text.go, json.go, zip.go）
2. **通用映射器** - 基于反射的自动模型创建（mapper.go）
3. **回调机制** - 灵活的文件类型处理（parser.go）

### 架构层次
```
工具层 (utils/upload/)
├── parsers/          # 模块化解析器
│   ├── text.go        # TXT/MD 解析器
│   ├── json.go        # JSON 解析器
│   ├── zip.go         # ZIP 解析器
│   └── parser.go      # 解析器管理器析器管理器
├── mapper.go           # 通用模型映射器
├── types.go           # 类型定义定义
    ↓
服务层 (services/)
├── 通用映射器 + 业务逻辑
    ↓
控制器层 (controllers/)
├── API 端点处理
    ↓
中间件层
├── 认证、验证、限流
```

### 回调函数机制
- 灵活的文件类型处理

- 高度可复用的架构

### 标签配置系统
- `json_field`: 映射 JSON 字段到模型字段
- `default`: 设置默认值
- `required`: 标记字段为必填
