# 文件上传和导入功能总结

## 项目概述

为小说管理系统后端添加通用的文件上传和导入功能，支持提示词、作品和章节三个核心模块的数据导入。

## 🎯 核心功能

### 支持的模块和格式

| 模块 | 支持格式 | 说明 |
|------|---------|------|
| 提示词 | .txt, .md, .json, .zip | 支持单个和批量导入 |
| 作品 | .json | 导入作品元数据 |
| 章节 | .txt, .md, .zip | 导入章节内容 |

### 文件大小限制

- 单个文件: 最大 10MB
- ZIP 文件: 最大 50MB
- ZIP 解压后: 最大 100MB
- ZIP 内文件数: 最多 100 个

## 🚀 技术架构

### 后端架构层次

```
工具层 (utils/upload/)
  ├── parsers/          # 模块化解析器
  │   ├── text.go        # TXT/MD 解析器
  │   ├── json.go        # JSON 解析器
  │   ├── zip.go         # ZIP 解析器
  │   └── parser.go      # 解析器管理器
  ├── mapper.go           # 通用模型映射器
  ├── types.go           # 类型定义
    ↓
服务层 (services/)
├── 通用映射器 + 业务逻辑
    ↓
控制器层 (controllers/)
└── API 端点处理
    ↓
中间件层
├── 认证、验证、限流
```

### 🚀 核心创新

### 反射+标签映射系统
- **零重复代码**: 新增业务模块只需在模型上添加 `json_field` 标签
- **类型安全**: 编译时检查，运行时自动映射
- **高度可扩展**: 新增模块只需配置标签，无需重复代码

### 回调函数机制
- **灵活处理**: 通过回调函数处理不同文件类型
- **逻辑分离**: 业务逻辑与解析逻辑完全分离
- **高度复用**: 通用架构，易于扩展

### 标签配置系统
- `json_field`: 映射 JSON 字段到模型字段
- `default`: 设置默认值
- `required`: 标记字段为必填

## 📊 架构优势

### 🔄 零重复代码设计
```go
// ❌ 传统方案：每个业务模块都要重复实现
// Prompt 模块
func processJson(content []byte) ([]*models.Prompt, error) { ... }
func processText(content []byte) ([]*models.Prompt, error) { ... }

// ✅ 新方案：只需在模型上添加标签
type Prompt struct {
    Title string `json_field:"title"`
    Content string `json_field:"content"`
}

// 业务模块复用通用映射器
func (i *PromptImporter) Import(ctx, file, userID) (*ImportResult, error) {
    callback := func(fileType, content, filename) ([]interface{}, error) {
        return i.mapper.MapFromJson(content, reflect.TypeOf(Prompt{}), userID)
    }
    // ... 其他逻辑
}
```

### 🎯 类型安全保障
- **编译时检查**: 标签配置错误在编译时发现
- **自动类型转换**: 反射自动处理类型匹配
- **零运行时错误**: 避免手动类型转换错误

### 高度可扩展性
- **新增业务模块**: 只需模型标签配置
- **新文件格式**: 添加对应解析器
- **灵活配置**: 通过标签控制映射行为
