# 文件上传和导入功能需求分析

## 1. 功能概述

为小说管理系统后端添加通用的文件上传和导入功能，支持多个模块（作品、章节、提示词）的数据导入。

## 2. 业务需求

### 2.1 支持的模块
- **提示词模块**: 支持导入 .txt, .md, .json, .zip 格式
- **作品模块**: 支持导入 .txt, .md, .json 格式（作品元数据）
- **章节模块**: 支持导入 .txt, .md 格式（章节内容）

### 2.2 文件格式说明

#### 提示词导入格式
- **.txt/.md**: 单个提示词，标题为文件名，内容为文件内容
- **.json**: 批量导入，格式如下：
```json
[
  {
    "title": "提示词标题",
    "content": "提示词内容",
    "description": "描述",
    "primaryTag": "标签",
    "categories": ["分类1", "分类2"],
    "footerTags": ["标签1", "标签2"]
  }
]
```
- **.zip**: 包含多个 .txt/.md/.json 文件的压缩包

#### 作品导入格式
- **.json**: 作品元数据
```json
{
  "title": "作品标题",
  "description": "作品描述",
  "category": "分类",
  "outline": "大纲"
}
```

#### 章节导入格式
- **.txt/.md**: 章节内容，第一行为标题，其余为内容

## 3. 技术设计

### 3.1 后端架构

#### 3.1.1 通用文件上传服务
```
backend/utils/upload/
├── upload.go          # 文件上传处理
├── parser.go          # 文件格式解析
└── validator.go       # 文件验证
```

#### 3.1.2 导入接口设计
```go
// 通用导入接口
type Importer interface {
    Import(ctx context.Context, file *multipart.FileHeader, userID uint) (ImportResult, error)
}

// 导入结果
type ImportResult struct {
    Success      int      `json:"success"`
    Failed       int      `json:"failed"`
    Total        int      `json:"total"`
    Errors       []string `json:"errors,omitempty"`
}
```

### 3.2 API 端点设计

#### 提示词导入
- **POST** `/api/v1/prompts/import`
- **请求**: multipart/form-data, file 字段
- **响应**: ImportResult

#### 作品导入
- **POST** `/api/v1/works/import`
- **请求**: multipart/form-data, file 字段
- **响应**: ImportResult

#### 章节导入
- **POST** `/api/v1/works/:workId/chapters/import`
- **请求**: multipart/form-data, file 字段
- **响应**: ImportResult

### 3.3 安全验证

1. **文件大小限制**: 
   - 单个文件: 最大 10MB
   - ZIP 文件: 最大 50MB

2. **文件类型验证**:
   - MIME 类型检查
   - 文件扩展名验证
   - 内容格式验证

3. **权限验证**:
   - 用户认证
   - 资源所有权验证（章节导入时验证作品所有权）

### 4.1 导入对话框组件
- 复用现有的 `ImportPromptsDialog` 组件
- 创建通用的 `ImportDialog` 组件供其他模块使用

### 4.2 API 调用
```typescript
// 提示词导入
export const importPrompts = (file: File) => {
  const formData = new FormData();
  formData.append('file', file);
  return axios.post('/prompts/import', formData);
};

// 作品导入
export const importWork = (file: File) => {
  const formData = new FormData();
  formData.append('file', file);
  return axios.post('/works/import', formData);
};

// 章节导入
export const importChapters = (workId: number, file: File) => {
  const formData = new FormData();
  formData.append('file', file);
  return axios.post(`/works/${workId}/chapters/import`, formData);
};
```
