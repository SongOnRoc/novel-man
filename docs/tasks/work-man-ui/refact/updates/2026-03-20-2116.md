# 本次做了什么

- 将前面的设计与结构映射进一步收敛成一份可执行实施计划。
- 计划按四个 chunk 拆分：
  - 重写章节目录页身份
  - 建立单章节主入口
  - 整合编辑页与分析入口
  - 接入段落选择模式
- 为每个任务明确了目标文件、测试文件、最小实现方向、验证命令和阶段提交建议。

# 为什么这么做

- 到当前阶段，抽象设计已经足够多，下一步真正需要的是实施顺序与修改边界。
- 如果没有分阶段计划，后续实现很容易再次陷入“边做边改方向”的状态。
