# 本次做了什么

- 将章节分析工作区从“容器壳层”升级为“最小真实结果工作区”。
- 新增分析结果数据结构与生成逻辑：
  - `frontend/src/features/chapters/lib/chapterAnalysis.ts`
- 升级桌面端和移动端分析组件，使其支持展示：
  - 分析类型标签
  - 结果标题
  - 结果摘要
  - 结果条目列表
- 在阅读态与编辑态中接入结果生成逻辑：
  - 点击“分析”时，生成整章的大纲结果
  - 片段选择后，生成片段级大纲结果并带入分析工作区

# 为什么这么做

- 如果分析工作区一直只有“提取大纲 / 提取角色”的占位文案，就无法验证后续真正的结果态信息结构是否成立。
- 本轮先做最小可复用的数据结构和结果展示，让阅读态与编辑态都拥有真实结果态，而不是继续停留在空壳阶段。
