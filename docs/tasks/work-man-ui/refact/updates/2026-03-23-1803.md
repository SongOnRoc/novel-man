# 本次做了什么

- 继续推进分析工作区，使“整章分析”不再固定只走大纲结果，而是支持在工作区内切换分析类型。
- 新增组件：`frontend/src/features/chapters/components/ChapterAnalysisTypeTabs.tsx`
- 升级了桌面端和移动端分析工作区组件，使其支持：
  - 大纲 / 角色 两种分析类型切换
  - 切换后即时刷新结果展示
- 在阅读态和编辑态中抽取并统一了：
  - 整章分析的源段落
  - 当前分析类型状态
  - 根据类型重新生成分析结果的入口函数
- 补充测试验证：
  - 整章分析支持切换到角色结果
  - 编辑态同样支持整章分析类型切换

# 为什么这么做

- 如果整章分析只能默认生成大纲结果，而角色结果只存在于片段模式中，分析工作区的能力边界就仍然不完整。
- 当前这一步让“整章分析”和“片段分析”在分析类型层面趋于一致，后续再接真实数据源时也更容易收口。
