## 为什么这么做

- 章节目录页是当前章节系统中最后一个明显停留在骨架态的页面，缺少真正可用的目录导航能力。
- 本次实现优先覆盖“用户能否快速定位章节”的关键路径，而不是继续添加次级能力。
- 使用“前端目录视图模型 + 双模式目录组件”的方案，可以在不依赖新后端接口的前提下，先把目录交互做完整。
