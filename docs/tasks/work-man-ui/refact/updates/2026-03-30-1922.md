# 本次做了什么

- 重构了 `frontend/src/app/(main)/works/[id]/page.tsx` 的整体 UI 布局。
- 将页面改为“上方作品信息区 + 下方作品管理区”的上下结构，移除了原先大卡片包大卡片的布局方式。
- 保留了作品标题、状态、更新时间、作品 ID、简介、4 个统计指标、4 个操作按钮、tabs 与全部管理内容。
- 将章节列表、草稿列表、占位模块与 skeleton 同步改为更轻、更紧凑的跨端样式。

# 为什么这么做

- 当前页面的问题核心是 UI 容器过多、层级过重、移动端单个信息块占屏过大，而不是信息本身过多。
- 本轮调整重点是只改 UI，不删任何实质内容和交互，让同样的信息以更高效、更现代的方式被阅读和操作。
