# 章节目录页补完 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将章节目录页从平铺列表升级为支持分卷树、自动定位、纯章节退化模式和分页的可用目录工作区。

**Architecture:** 页面层继续负责全量章节获取、查询参数解析和目录视图模型构建；目录工具条只负责触发搜索与展开控制；目录树组件负责根据“分卷树模式 / 纯章节目录模式”渲染结构与高亮。通过页面测试覆盖树结构、搜索、分页、展开状态优先级和退化模式，保证与现有重排、删除、导入入口兼容。

**Tech Stack:** Next.js App Router, React, TypeScript, TanStack Query, Vitest, Testing Library

---

严格遵循：

明确把原始 `volumeId` 映射到连续展示序号：

```ts
// 例如 10 -> 第 1 卷, 30 -> 第 2 卷
```

不要直接把原始 `volumeId` 写进展示文案。

- [ ] **Step 6: 解析 `currentChapterId` 并定位目标项**

最小逻辑：

```ts

```

- [ ] **Step 7: 计算自动切页结果**

要求：
- 树模式下定位到所属分卷页
- 纯目录模式下定位到所属章节页
- 后续分页状态优先采用这个目标页

- [ ] **Step 8: 定义目录分页常量**

例如：

```ts
const DIRECTORY_PAGE_SIZE = 8;
```

- [ ] **Step 9: 实现树模式分页**

要求：
- 按分卷组分页
- 同一分卷不能被切到两个页

- [ ] **Step 10: 实现纯目录模式分页**

要求：
- 按章节条目分页
- 与当前目录页现有分页组件兼容

- [ ] **Step 11: 实现搜索过滤结果**

要求：
- 搜索前做 `trim()` 和小写归一化
- 命中章节时仅保留命中章节，但保留所属分卷
- 命中分卷标题时保留整组章节

- [ ] **Step 12: 实现搜索空状态**

当过滤后无结果时，准备明确空状态数据，让页面渲染：`没有匹配的章节或分卷`

- [ ] **Step 13: 实现过滤后结果分页**

要求：
- 分页基于过滤后的可见目录结果，而不是原始全集
- 搜索词变化后默认回第 1 页

- [ ] **Step 14: 定义分页优先级顺序**

明确顺序：
1. 先应用搜索过滤结果
2. 再计算当前章节自动定位页
3. 最后在无定位目标时回退到第 1 页

- [ ] **Step 15: 实现展开状态基础存储**

页面层维护：

```ts
const [expandedKeys, setExpandedKeys] = useState<string[]>([]);
```

- [ ] **Step 16: 实现搜索命中组强制展开**

保证搜索结果中的命中分卷不会被折叠到不可见。

- [ ] **Step 17: 实现当前章节所属组强制展开**

保证当前章节所在分卷不会被折叠到不可见。

- [ ] **Step 18: 实现搜索前手动展开状态恢复**

要求：
- 搜索前记录用户手动展开状态
- 搜索清空后恢复该状态
- 然后重新应用当前章节定位规则

- [ ] **Step 19: 实现当前页范围内的全部展开 / 全部折叠控制**

要求：
- 仅当前页分卷可响应全部展开 / 全部折叠
- 不跨页修改未渲染分页的展开状态
