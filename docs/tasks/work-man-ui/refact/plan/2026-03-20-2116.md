# 章节系统重构实施计划

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前章节管理页重构为“目录页 + 单章节工作区 + 分析工作区 + 段落选择模式”的统一章节系统骨架，并保持现有编辑能力可平滑迁移。

**Architecture:** 先重写目录页身份，再建立单章节主入口，随后把现有预览与编辑能力吸收到统一章节工作区中，最后再补分析工作区与段落选择模式。整个过程优先复用现有 `TiptapEditor` 能力，不再继续叠加“管理后台式章节页”。

**Tech Stack:** Next.js App Router、React、TypeScript、shadcn/ui、现有 chapter/work hooks、Tiptap 编辑器

---
