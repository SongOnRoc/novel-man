# 作品详情页跨端 UI 重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不删减现有信息与交互的前提下，重构作品详情页为更紧凑、现代、跨端一致的工作台布局。

**Architecture:** 保留页面现有数据查询与 tab 逻辑，仅重构页面视觉结构。顶部区域改为轻量作品信息区，统计信息收敛为紧凑指标块；下方管理区保留 tabs 和全部模块，但使用更轻的区块与行式列表承载内容。

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS, shadcn/ui
